# Community 管理后台

管理员登录后，从侧栏或「设置 → 管理后台」进入 `/admin`。普通成员不会看到入口；直接访问也会被路由守卫拒绝。每个管理 API 仍在服务端检查当前管理员身份，OAuth 调用另需对应管理 scope。

后台参考 Misskey 的分组侧栏、概览卡片和分区设置表单，使用 Community 自己的配色与组件。独立布局不显示时间线侧栏、推荐关注或手机发帖按钮，支持窄屏导航、键盘焦点、浅色与深色主题。

## 页面与实际能力

| 页面 | 功能 |
| --- | --- |
| 概览 | 本地用户、收录帖子、近 30 天新增用户、待处理举报；失败显示不可用而不是伪造为零 |
| 用户管理 | 搜索、来源/状态过滤、分页、详情、注册批准/拒绝、停用/恢复登录、封禁/解除封禁 |
| 举报与内容 | 处理状态与账号过滤、游标分页、详情、认领/取消认领、处理/重新打开、关联帖子删除 |
| 自定义表情 | 复用已有上传、分类、别名、角色限制、本地/远程与批量管理 |
| 联邦中继 | 查看真实中继状态、添加、启用、停用与删除 |
| Matrix 服务 | 区分内置 Matrix 与可选桥接，展示非敏感配置与可用的连接诊断 |
| 站点设置 | 社区规则增删改、验证码配置；密钥只写不回显，环境变量管理项提示只读 |
| 数据迁移 | 复用完整站点备份预检、任务与执行报告，保留原有确认步骤 |

管理操作使用明确确认并防止重复提交。标记举报已处理不会自动封禁账号或删除帖子；删除帖子不会自动关闭举报。停用登录与封禁不会修改「关注需要审核」设置。管理员不能停用、封禁或拒绝自己的账号。服务端会重新检查已有会话的账户状态。

未提供没有实际后端支持的通用站点信息编辑、Matrix 在线启停、警告邮件或账号静默限制。部署参数仍由环境配置管理。没有管理员帖子列表 API，因此内容处置以举报关联帖子为入口。原站用户迁移能力及限制见 [数据迁移说明](data-migration.md)。

## Logo

新标志将 Community 的首字母 C 与对话气泡合并，以透明负空间适配深浅背景。`frontend/public/logo.svg` 与 `LogoIcon.vue` 使用相同矢量路径，favicon 与页面标志保持一致；没有运行时图片生成或外部图标请求。

## 验证

前端：在 `frontend` 目录执行 `npm ci`、`npm run lint`、`npm test`、`npm run build`。新增测试覆盖后台路由边界、统计失败重试、管理 API 请求、分页、操作取消/失败、删除与举报状态相互独立、敏感配置保留等行为。

后端变更涉及管理员账号与内容 API、举报、统计、验证码及认证边界，需要执行相应包的回归。真实浏览器验收应使用独立测试账号和内容，覆盖桌面与手机布局、普通成员越权、管理操作与撤销/恢复。不要在真实用户数据上试验封禁、删除或迁移。

参考信息架构：[Misskey 管理导航](https://github.com/misskey-dev/misskey/blob/2026.10.0/packages/frontend/src/pages/admin/index.vue)、[概览](https://github.com/misskey-dev/misskey/blob/2026.10.0/packages/frontend/src/pages/admin/overview.vue)、[设置](https://github.com/misskey-dev/misskey/blob/2026.10.0/packages/frontend/src/pages/admin/settings.vue)。仅参考结构，未复制其品牌与页面实现。

本轮验证：前端 50 个测试文件、202 项测试通过，lint 与类型检查/生产构建通过；后端 admin、report、middleware、account、serializer、common、captcha 七个包回归通过。历史日志和私有测试凭据不提交仓库。

真实 Chromium 验收覆盖 1440/390/320px 的全部 8 个管理页面、深色主题、手机导航、普通成员访问限制、停用/恢复登录、举报认领/删帖/处理、规则增改删。窄屏表格使用独立横向滚动区域并支持键盘访问。验证码提交失败使用浏览器拦截模拟，未修改全局验证码配置；未向外部添加中继或执行整站迁移。

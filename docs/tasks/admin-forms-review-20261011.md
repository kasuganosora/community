# 后台表单设计与可用性复核（2026-10-11）

本轮按 [emil-design-eng 设计技能（固定版本 e8a175d）](https://github.com/emilkowalski/skills/blob/e8a175de22ae1e49370fc144c1f3bb9aeedf988d/skills/emil-design-eng/SKILL.md) 审查并修复设置表单，继续使用现有 Vue 组件和原生表单控件，没有新增动画库。

## 设计审查

| Before | After | Why |
| --- | --- | --- |
| 环境管理的 S3 字段显示为无边框段落，看起来像失效的表单 | 带边框、可选中复制的只读控件，附部署来源徽标 | 清楚区分可编辑和锁定状态，不暗示保存可以覆盖部署 |
| 反复显示笼统锁定提示，没有可执行的下一步 | 统一说明，展开后列出对应配置键和交接、重启步骤 | 管理员能定位部署配置；不返回密钥值 |
| 只读或重启提示覆盖字段原有说明 | 同时保留字段用途、来源和生效说明 | S3 公开地址、路径风格等语义不能因锁定而消失 |
| 文案要求保存前测试，接口却只能测试已保存配置 | 明确保存、测试已保存配置、重启生效的顺序 | 避免假保存和错误的生效预期 |
| 控件与提示缺少无障碍关联 | 使用 `aria-describedby`，校验失败时标记字段 | 键盘和辅助技术用户可以获得完整说明 |
| 异步结果可能在切换账号后返回 | 会话变更立即清空草稿和密钥输入，并丢弃迟到结果 | 避免跨账号显示配置和操作结果 |
| 键盘按下按钮也触发缩放 | 按压缩放排除键盘焦点状态 | 高频键盘操作保持即时和稳定 |
| 触屏沿用桌面的控件尺寸 | 粗指针下至少 44px 触控目标，输入字号 16px | 改善点击准确性，避免手机输入自动放大 |
| 触屏可能保留悬停样式 | 悬停效果只用于支持悬停的精细指针 | 防止触摸后出现粘滞反馈 |
| 减少动态效果模式仍有按压位移 | 该模式下取消按压缩放 | 完整尊重减少动态效果偏好 |

## 实际验证

使用独立 MySQL 数据库、Redis 分区和 `18097` 后端，以独立测试管理员验证；前端输出到独立目录，没有修改性能测试使用的前端文件或账号。测试结束后停止该后端。

- 浏览器 **42 项检查全部通过，页面异常为 0**。常规、品牌、注册、性能、数据库、外部服务、邮件、存储、安全共 9 页，在 1280px／320px、浅色／深色组合下均无横向溢出。
- 通过真实表单修改站点名称，再以认证 HTTP 读取验证数据库持久化；在 `finally` 中恢复原值。
- 验证部署字段不可编辑、来源键名可读、键盘 Enter 可展开交接说明；真实调用已保存配置的本地存储诊断，没有外部写入。
- 另用触屏浏览器上下文验证粗指针控件至少 44px、输入字号 16px、原生数字范围校验及减少动态效果设置。该项是浏览器触屏模拟，未宣称物理手机测试。
- 7 项组件测试通过，覆盖可编辑数据类型、部署只读、密钥保留与清除、切换页面和账号的迟到响应、仅测试已保存配置。
- 后端设置回归通过，覆盖部署键名元数据、密钥遮盖及部署覆盖写入返回 409。Vue 类型检查、定向 ESLint、独立 Go 和 Vite 构建通过。

本次运行的详细证据保存在 QA 环境 `/tmp/community-admin-form-qa/`：`browser-report.json`、`touch-report.json` 及邮件／存储不同尺寸主题的截图。临时运行证据不作为仓库内长期附件；此文记录已完成的验证及边界。

## 配置边界

**显式部署环境配置仍然只读，后台不能覆盖。** 页面提供明确的交接说明：部署管理员先备份，在环境变量或配置文件中移除对应项并重启；随后在后台填写、保存并测试，再按提示重启使连接配置生效。操作顺序需要部署管理员安排维护，不能把移除配置当成无中断切换。

密钥不回显；留空保留原值，明确清除需确认。SMTP 测试不发送邮件，S3 测试不创建存储桶或读写测试对象；连接检查成功不证明实际发送、写入或公开下载均正常。切换存储不迁移旧文件，须另行保持历史附件可达性。

# 异步交互与输入框集成审查

日期：2026-10-14。按现有 Emil Design Engineering 规范检查即时反馈、焦点、触控区域、失败恢复和页面切换。

| Before | After | Why |
| --- | --- | --- |
| 点击搜索后，旧页等待目标页代码下载，像没有响应 | 共用路由壳先提交导航，在目标页显示加载；权限校验期间显示中立进度 | 用户能立即看见操作结果，权限边界继续生效 |
| 群组搜索同时展示加入和申请加入 | 按已知加入规则只给一个操作；简化未知群介绍，统一卡片间距 | 避免让用户猜测两个相似按钮的区别 |
| 首页保留列表时，重试可能发错请求或无反应 | 记录失败的是刷新、后页还是前页，重试相同请求并立即显示等待状态 | 恢复失败的操作，保留正确分页游标 |
| 加入列表读取失败还显示空列表；重复点击可能并发改动 | 失败、空态互斥，提供重试；写入期间阻止重复，切账号后忽略旧结果 | 网络失败不能冒充没有数据 |
| 群组加入可能无限等待；私信成功发送还卡在回读 | 入群操作有总时限并保留查询操作；写入成功立即释放草稿，详情后台更新 | 避免重复加入和重复发送 |
| TDesign 外壳和内部输入区域各自画焦点边框 | 共用组件仅保留外壳焦点；强制颜色模式保留明确轮廓 | 避免双框，同时保持键盘可访问性 |
| 搜索清除图标不可用键盘触发，触控区域偏小 | 原生清除按钮支持 Tab/Enter，清除后回到输入框，触控区域达到 44px | 清除不应依赖鼠标悬停，也不应误触搜索 |
| 消息框原生缩放手柄突兀，窄栏工具与提示拥挤 | 限高自动增长、内部滚动，工具按钮至少 44px，窄栏隐藏快捷键文字 | 长内容不破坏会话布局，发送动作保持可见 |
| 后台只读长文本未给状态标记预留空间 | 只读 textarea 与 input 同样预留空间，小屏标记移至控件下方 | 防止“部署锁定”盖住首行文本 |

## 验证边界

最终前端全量测试 **117 文件 / 595 项通过**，ESLint、类型检查与生产构建通过。补充回归覆盖私信手动重试与后台轮询互斥、共享读取的错误清理、输入法组合期间不误发及搜索清除后回焦。

输入细节浏览器验收：共享搜索框 81 项检查、设置焦点与后台只读长文本 23 项检查通过；群聊与私信在 1440px 浅深色、390px 深色、320px 浅色共 8 个组合验证输入增长/回缩、长文滚动、附件发送与强制颜色焦点。代表性截图已视觉复核，无横向溢出。证据位于 `/tmp/community-search-input-review/`、`/tmp/community-settings-focus-browser/`、`/tmp/community-chat-input-review/`。

浏览器使用真实 Vue 页面和可控制的合成接口，验证慢页面代码、慢权限、慢 API、重复操作、桌面/手机布局。没有向真实账号发送消息、邀请或修改线上配置。这些检查不代表外部 Matrix 联邦服务的延迟已消除，也不声称每个后台操作都做过生产环境故障注入。

# 网页群聊界面与交互审查

日期：2026-10-13。此记录覆盖网页实现；跨服务器联调、服务端授权和性能结果见主实施报告。

## 设计依据

使用 `emilkowalski/skills` 中的 `apple-design` 与 `emil-design-eng`：分组清楚、稳定的操作位置、可撤销/可恢复的操作反馈、系统字体、键盘操作、触摸尺寸及减少动态效果。没有新增动画框架或 Matrix 客户端 SDK。

| Before | After | Why |
| --- | --- | --- |
| 消息入口只有私信，旧会话带 AP 语义 | 私信与原生群聊并列，独立的数据和操作入口 | 避免用户将群聊与 AP 私信桥接混淆 |
| 社区推荐栏、发布帖子浮动按钮占用聊天空间 | 群页使用群列表与聊天区，手机切换列表/会话，隐藏发布浮钮 | 优先消息阅读、发送与附件操作 |
| 群身份、成员、权限集中在聊天正文会过载 | 群资料与成员放入可关闭的原生对话框抽屉 | 清晰分组，原生焦点约束与 Escape 关闭 |
| 原生群详情抽屉中的确认层会被 top layer 遮挡 | 成员危险操作使用抽屉内确认；退出前关闭抽屉，取消后恢复 | 确认按钮可点击且键盘可达，避免弹窗互相遮挡 |
| 群成员头像被通用 `span { flex: 1 }` 拉伸 | 固定头像宽高，只有文字内容弹性伸缩 | 修复真实截图中的横向胶囊头像 |
| 添加附件使用不存在的图标名 | 使用现有 `file-add` 图标并提供可访问名称 | 保证可发现且可读屏操作 |
| 网络失败容易重复发送、草稿丢失 | 保留请求内容和事务 ID，重试复用；部分成功有明确恢复提示 | 让用户明确哪些内容仍待发送 |
| 加密变化仅禁用按钮会留下上传和重试 | 同时阻止发送、取消上传、关闭选择器；保留可选择复制的只读草稿 | 避免在已知加密状态下误发送明文 |
| 外部富文本和表情图片可能直接指向远端 | 净化文本；自定义表情、头像和附件走受控授权入口与临时 Blob URL | 不把登录凭据放入 URL，不直接显示远端跟踪图片 |
| 视频文件可能被通用媒体组件自动播放 | 所有音视频作为文件展示与下载，不创建播放器 | 保持本次明确的功能边界 |
| 退出/换群可能静默丢弃输入 | 存在草稿时确认；离开群后不自动因消息重加入 | 保持可预测的群生命周期 |

## 交互覆盖

- 创建非加密公开或邀请群；说明目录可见性；邀请部分失败单独提示，不谎称群创建失败。
- 群链接/别名预览、保留 via 与签名目录预览引用、显式加入/申请；邀请接受/拒绝、撤销申请；加密与空间转客户端提示。
- 群资料、头像、静音、成员分页、邀请、权限等级、批准/拒绝申请、踢人、封禁/解封、复制群地址。
- 文本、提及、回复、删除、明确告知的删除并重发；普通表情、自定义表情与回应。
- 附件选择、粘贴与拖拽，最多两项并行上传，大小与数量读取服务端限制；进度、移除/取消、重试、图片原图与下载。
- 单一增量同步通道；先取得同步水位再读取历史，旧事件更新按 ID 合并，不用远端时钟重新排序。
- 历史分页保持滚动位置，阅读底部才更新已读，输入状态与未读提示；后台标签不误清未读。
- 键盘发送、Escape 关闭对话框、可见焦点、深浅色、320–1920 宽度与粗指针触摸尺寸。

## 自动验证

`npm run test -- src/domains/message --maxWorkers=1`：10 个测试文件、41 项通过，其中本功能新增 21 项。随后补充 2 项同步超限回归，相关 8 项定向测试通过，验证暂停后仍可切群、读历史、手动刷新和恢复同步。其余测试覆盖加密边界、上传取消、上传未完成时阻止发送、幂等/部分失败重试、同步初始竞争窗口、离开/账户切换、私有表情授权与降级、HTML 净化、禁用音视频播放器和下载重试。

`vue-tsc --noEmit -p tsconfig.app.json` 和新增/修改界面的 ESLint 通过。运行时模板还必须由 Vite 构建与真实浏览器覆盖：类型检查不能代替模板运行验证。

人工视觉检查基于实验环境 Chromium 截图，包括桌面会话、390 深色会话及群详情；已据此修复头像伸缩和缺失附件图标。截图并非真实手机设备验证。外部 Matrix 行为由单独联调记录确认，不以界面单测代替联邦验收。

## 入口补充审查

原实现将群聊入口藏在消息页的二级切换中，桌面侧栏缺少群组，手机底部也没有消息入口。补充侧栏「群组」、消息页「新建群组」和账户菜单「群组」；手机底部第四项调整为「消息」，收藏仍可从账户菜单打开。群页只高亮对应的导航项，收起文字的侧栏按钮也提供可访问名称。

Chromium 在 320、390、1024、1920 四种宽度验证了入口、创建表单、关闭后再次打开、导航选中状态和无横向溢出；通过快捷入口实际创建了测试群，并确认登录跳转保留创建意图。共 10 项浏览器检查通过，无 JavaScript 错误。导航、布局及消息相关的 12 个测试文件、48 项测试，以及生产构建、类型检查、修改文件 ESLint 通过。原始截图和报告位于本次环境 `/tmp/community-groups-qa/navigation-*`。

# 推荐 P0/P1 实施与验收

日期：2026-10-14（北京时间）。基于 master `dbfca29` 实施；对应[计划](community-recommendation-research.md)、[功能与运行说明](../recommendations.md)、[独立隐私验收](recommendation-privacy-acceptance.md)。所有真实 API、浏览器和引擎检查都在隔离实验环境执行，没有修改生产数据库。

## 交付范围

- 首页推荐改为专用排名接口，支持关闭、公开发现和个性化；关注时间线保留原接口。
- SQL 当前资格、远端发现许可、引用整卡检查、个人排除规则与站级禁推统一用于推荐、关注建议、热点和专用索引。
- Redis 保存有界候选和签名分页窗口；权限撤回、偏好修改、策略停用均检查当前状态。
- Meilisearch 词法增强接入后台候选生成；语义配置、累计预算、索引版本审批和故障回退具备实现与测试，未连接外部语义模型。
- 热点提供滚动 24 小时／7 天、本地／本站已知联邦范围、精确作者数和近期话题标记；旧 trends 与建议账号接口保留兼容形状。
- 设置页提供阅读语言与反馈撤销；管理后台提供内容发现运行状态、站级禁推和审计。

## 开发环境短测

隔离 MySQL 8.4.11 数据库，40 个作者、1,000 条近期公开帖；每页 20 条，每个接口 8 个闭环并发、160 次请求。应用 `GOMAXPROCS=2`、数据库连接池 4、开发 SQL 日志开启。首屏重复请求会复用 5 秒内的窗口，这不是每次冷构建的性能，也不是固定开放到达率压测。

| 接口 | 请求/秒 | p50 | p95 | p99 | 错误 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 推荐首屏 | 72.24 | 107.61ms | 135.86ms | 170.61ms | 0/160 |
| 同一快照后页 | 133.13 | 57.04ms | 96.36ms | 111.89ms | 0/160 |
| 热点话题 | 12.05 | 662.88ms | 718.67ms | 734.26ms | 0/160 |

热点修复前在相同并发下有 157/160 次请求因扫描槽满而立即拒绝；修复后保留 2 个 SQL 执行槽、增加 16 个等待席位，排队和查询共同受原 3 秒期限限制。2 并发的先前基线 p95 约 198ms，8 并发后的等待明显增加，因此不能将零错误描述为高吞吐。测试结束的应用 RSS 为 66,380 KiB，高水位 71,272 KiB，仅为进程观测值，不是内存硬上限。

最终上述结果在没有活跃 Go 编译的情况下取得。一轮受额外 race 首次编译干扰的结果单独保留，没有混入最终表；额外 race 编译已取消，不声明 race 检查通过。失败、受干扰、最终三份记录均在实验目录保留。推荐热页本次短测达到计划初始时延目标；持续负载、混合大数据集和联邦／Matrix 同机退化门槛仍未验证。

## 发布边界

推荐首次部署默认关闭；Meili 未审核版本不会自动向用户开放增强。当前验收不等于证明相关性、点击率或线上吞吐提升。

计划中的 1 万账号／100 万帖子、固定开放到达率至少 10 分钟 × 3 轮、大规模 SQL 扫描／连接等待、多个真实 API 副本冷启动及实际 Redis Cluster 的故障测试，仍属于上线前的规模验收。短时开发负载不能替代这些门槛。当前单元测试覆盖共享租约、缓存预算、失租拒绝和 Redis Cluster 键槽约束，但没有将其写成真实多机验证。

外部语义模型的隐私保留策略、费用和排序质量未验证；生产反向代理是否保留 `no-store` 需部署时确认。尚未送达本站的远端权限变更不能即时获知，此前合法发给客户端的数据无法远程删除。P2 曝光／质量实验与扩展、P3 公开 Matrix 群推荐不在本次交付范围。

实验日志、截图和私有账号夹具保存在 `/tmp/community-discovery-qa/`，不提交账号令牌或数据库凭据。仓库中的测试可重跑；部署与配置说明见[推荐运行文档](../recommendations.md)。

# 用户设置页设计审查（2026-10-11）

按 [Apple design skill](https://github.com/emilkowalski/skills/blob/e8a175de22ae1e49370fc144c1f3bb9aeedf988d/skills/apple-design/SKILL.md) 的分组、方向感、空间一致性、反馈和可访问性原则审查 `/settings`。这不是 Apple 官方认证审核。

## Before / After / Why

| Before | After | Why |
| --- | --- | --- |
| 外观、资料、安全、过滤器和链接全部堆在一个长页面 | 五类导航：个人资料、显示偏好、账号安全、内容过滤、更多 | 缩短寻找设置的路径；URL 保留分类，刷新和前进后退可恢复位置 |
| 右侧推荐关注和手机发布按钮占用编辑空间 | 设置页隐藏推荐栏及浮动发布按钮，扩展内容列 | 设置任务更集中，避免浮动按钮遮挡表单 |
| 表单控件、卡片、说明和操作区各自定义 | 以页面作用域统一间距、字号、背景、边框、焦点及操作区 | 不同分类使用同一种视觉层级，不影响时间线等页面 |
| 头像与封面操作挤在封面边界，挂件重复嵌套 | 图片操作置于封面下方，手机换行；挂件独立成组 | 清楚区分资料保存与挂件保存 |
| 通行密钥名称只用 placeholder，按钮与其他表单风格不同 | 可见 label、原生表单与统一按钮 | 辅助技术可识别字段，键盘 Enter 可提交 |
| 资料初始刷新可能覆盖已输入草稿 | 刷新完成时仅重置未修改的草稿 | 保留用户已完成的输入；分类切换同样保留草稿 |
| 通行密钥和授权应用失败时静默显示空列表 | 明确加载中、加载失败及重试状态 | 避免把网络失败误读为没有凭据或授权 |

## 实现与检查范围

`SettingsPage.vue` 管理分类并保留原有表单实例；`settings.css` 统一页面样式；`AppLayout.vue` 仅对设置路径调整布局；个人资料、通行密钥、授权应用和挂件组件做对应调整。没有改变密码、密钥或联邦通信的后端协议。

浏览器使用本地开发后端和测试管理员，未对 `c.hime.at` 生产账号进行设置修改。临时截图与执行证据保存在 `/tmp/community-settings-review/`，不包含仓库内凭据。

## 验证结果

- 五类设置在 1440 浅色、1920 深色、768 浅色、390 深色和 320 浅色下完成 115 项浏览器检查：分类位置、控件边界、无横向溢出、草稿跨分类保留、还原及密码校验全部通过。查看了各分类桌面／手机截图，并据此调整封面操作区和显示选项宽度。
- 7 项额外交互检查通过：真实保存资料并通过 API 确认持久化、手机保存按钮不被底栏遮挡、点击及键盘切换主题、刷新后保留分类与主题。测试结束恢复原资料。
- 设置测试 3 个文件共 6 项通过，包含新增的迟到刷新保留草稿，以及加载失败／重试行为测试。
- Vue 类型检查、Vite 生产构建、定向 ESLint 和 diff 空白检查通过。
- 手机为浏览器触屏模拟。未实际注册硬件通行密钥、修改密码或执行数据迁移；不把布局通过视为这些能力的端到端验证。

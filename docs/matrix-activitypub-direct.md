# Matrix 与 ActivityPub 私信

内置 Matrix 账号接收发送给本站账号的 ActivityPub Direct 帖子，并可在对应桥接房间发送新消息或回复。Misskey 中对应“指定用户可见”的帖子及回复，不是 Misskey 独立的 Chat 功能。

## 收件人与投递

房间由原始私信的明确参与者集合决定。新的 Matrix 消息仅投递给该集合中的其他账号；正文中的额外提及不会增加私信收件人。普通 Matrix 房间、加密事件和内部桥接事件不会进入 ActivityPub 出站队列。成员退出、封禁、屏蔽或房间参与者异常时停止外发。

Direct 消息中明确列在 `to/cc`、但本站尚未保存的远端账号，会通过受限联邦获取进行解析。每次最多解析 32 个未知账号，总预算 20 秒；超限或失败不截断收件人后返回成功，而是回滚以待重试。公开消息不会因此增加远端账号抓取。

Misskey 2026.10.0 的实测群私信存在源协议限制：它本站的另一位收件人可能只出现在 Mention 标签中，而不出现在发送给 Community 的 `to/cc`。Community 不能据此判断该账号是否有权接收后续私信，因此不会把普通提及自动扩展为收件人。桥接保证的是原 ActivityPub 消息明确提供的参与者集合，不承诺还原远端服务器未公开的完整群成员。

客户端消息与持久化出站任务在同一数据库事务保存。后台事务创建 Direct 帖子、ActivityPub 投递任务和 Matrix 事件映射，重试不重复创建帖子，也不把自己发送的消息再次桥回房间。Matrix 接受消息表示已保存及入队，不等于远端服务器已经接收；远端投递继续使用现有 ActivityPub 持久队列。

只处理升级后客户端新发出的消息，不扫描或补发历史 Matrix 消息。旧房间的“回复留在 Matrix”说明会更新。桥接房间不提供端到端加密；编辑及 Matrix 撤回不转发到联邦。

媒体下载与帖子的收件人权限不同：Matrix 下载要求登录，但已取得完整 MXC 地址的其他登录用户也可能下载其内容；ActivityPub 附件使用不可猜测的下载地址。不要把匿名下载被拒绝误认为逐房间附件权限或端到端加密。

## 回复、附件与头像

回复通过同房间的事件映射关联到原 ActivityPub 帖子。附件只接受发送者拥有的本站 Matrix 媒体，复制到 ActivityPub 媒体存储，避免任意 URL 抓取或引用他人的私有媒体。

远端头像经过受限下载、图片解码及大小校验后提供真实的 Matrix 媒体地址；原来只显示名字占位符的成员可随新的入站消息更新。头像抓取失败不阻塞私信。Matrix 用户自行设置的头像优先保留。房间图标与成员头像是独立设置，默认房间名称的首字母不代表成员头像同步失败。

未设置头像时，以完整账号 `username@domain` 的 SHA-256 生成稳定的对称几何图案；域名统一小写，用户名保留大小写。同名但不同站点的账号使用不同种子。默认头像为固定 128×128 PNG，在请求时内存生成，不写数据库或文件；浏览器可以长期缓存。网页、ActivityPub 资料及 Matrix 默认头像使用同一规则。真实头像不受此默认机制影响。

## 回归检查（2026-10-11）

- 前端 75 个测试文件、356 项测试，以及 lint、类型检查和生产构建通过。
- Matrix Homeserver 整包回归通过；最后的头像下载失败后恢复场景另经定向回归通过。
- 默认头像、serializer 与 ActivityPub 整包通过。默认图检查包括同账号稳定、域名区分、固定尺寸、无存储记录、非法媒体标识拒绝，以及客户端手动清空头像后的默认行为。
- 反向桥接覆盖事务回滚重试、重复事件、快速回复尚未完成投递的父消息、附件回复、已删除来源、精确收件人、退出或屏蔽后的拒绝，以及普通房间和加密消息不外发。

真实 Misskey 实验实例已接收到 Matrix 客户端发出的 Direct 回复，回复正确关联原帖子；重复客户端事务没有产生重复远端帖子。PNG 和普通文件均实际送达，Misskey 下载结果与原文件 SHA-256 相同。为避免可猜测的私信文件路径，联邦附件展示名使用不透明文件名，原名保存在描述中；不承诺远端展示原文件名。

受控签名 ActivityPub 服务与真实 Matrix HTTP 接口另验证了头像变更、`icon:null` 清空后动态默认头像、图片不可用时仍送达私信，以及用户自选头像保留。已知 MXC 地址的跨账号下载边界按上文记录，不能将匿名拒绝测试当作房间级媒体隔离证明。实验记录保存在本次工作区 `/tmp/community-feed-qa/matrix-avatar/`；前端自然入口截图和浏览器报告见 `/tmp/community-avatar-qa/`，凭据不入仓库。

升级前桥入的附件事件可能没有新的可信回复映射；此类回复不会猜测匹配或补发旧消息。可以在同房间发送新的普通消息，或回复有映射的文字消息。
